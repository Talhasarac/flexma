# Twemoji for server renders

`Twemoji.Mozilla.ttf` (mozilla/twemoji-colr v0.7.0, a COLR color font) draws
emoji in screenshots and exports, where the server has no emoji font of its
own (`render::base_fontdb`). Browsers keep using the system's emoji font in
the editor.

Emoji graphics: Twemoji by Twitter, Inc and other contributors, CC-BY 4.0.
Font build: Mozilla, Apache 2.0. See `LICENSE.md`.
